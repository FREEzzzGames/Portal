# 🕹️ Telegram Arcade Portal (Mini Apps)

Коллекция ретро-аркад, созданных на чистом HTML5 Canvas и JavaScript, оптимизированных для запуска в качестве **Telegram Mini Apps (TMA)*

---

## 🎮 Доступные игры

### 1. 🦆 Duck Mudack (Space Outpost)
* **Жанр:** Космический ретро-тир (Бесконечный режим).
* **Особенности:**
  * Бесконечные патроны и лазерный прицел.
  * Процедурно генерируемый космический фон, звезды и планеты.
  * Система комбо-очков и сохранение личного рекорда (`High Score`) через `localStorage`.

### 2. 🏎️ Retro Racer 360 (Championship Circuit)
* **Жанр:** Аркадные гонки с видом сверху (3 круга).
* **Особенности:**
  * Полупрозрачные экранные кнопки управления (слева — повороты, справа — газ и тормоз) для удобства на мобильных и ПК.
  * Реалистичная аркадная физика (замедление при выезде на траву, инерция).
  * Замер времени каждого круга, расчет итогового времени гонки.
  * Раздельное сохранение рекордов: лучший круг (`Best Lap`) и лучшее время гонки (`Best Race`).

---

## 🛠️ Технологии
* **HTML5 / CSS3:** Flexbox, Grid, адаптивная верстка, кастомные анимации.
* **JavaScript (ES6+):** Canvas API, `requestAnimationFrame`, оптимизированный игровой цикл (`dt`).
* **Telegram Web App API:** Автоматическое расширение на весь экран, синхронизация цветовой темы мессенджера.
* **Без зависимостей:** Чистый Vanilla JS без подключения сторонних тяжелых библиотек.
